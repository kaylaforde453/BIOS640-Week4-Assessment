# BIOS640-Week4-Assessment
This repository contains the files for the Week 4 assessment for BIOS 640: Introduction to Health Data Science Methods.

## Repository Structure

- `code/` contains the R Markdown source files used for the assessment.
- `data/` contains the cleaned NHANES dataset used for the analyses.
- `output/` contains rendered reports and other final outputs.

## Reproducibility

All analyses use relative file paths so the project can be reproduced after cloning the repository.
